# VoiceVerse Android project
Upload the contents of this folder to a GitHub repository. Open Actions, run **Build VoiceVerse APK**, then download the `VoiceVerse-debug-apk` artifact from the completed run and extract `app-debug.apk` on Android.

This is a debug/test APK. Text-to-speech uses voices installed on the phone. Character-inspired styles are pitch/rate presets, not exact voice clones. WAV files are saved in the app-private folder `Android/data/com.voiceverse.app/files/VoiceVerse`. This initial Android build shares text; public audio-file sharing and a Downloads picker are not yet implemented.
